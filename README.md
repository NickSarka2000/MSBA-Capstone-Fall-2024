# MSBA-Capstone-Fall-2024
This is the Repository including all of Team 5's final work for the Swire Coca-Cola Capstone Project from the Fall 2024 MSBA program at the University of Utah. It contains both the .ipynb and .html files containing code. The included contents are listed below.
1. Business Problem Statement
2. EDA Notebook
3. Modeling Notebook
4. Presentation slides (converted to PDF)

The slides were presented to the Swire team and other MSBA students in late November 2024. The data used for this project was provided and is owned by Swire Coca-Cola.
